# Sistema de Gestão de Estoque de TI — Web (Frontend)

Interface Single Page Application (SPA) desenvolvida em **React**, **TypeScript**, **Vite**, **Tailwind CSS** e **TanStack React Query** para operação diária do almoxarifado e balcão de suporte de TI.

## Tecnologias
- **React 19 + TypeScript**
- **Vite** (HMR e proxy de API)
- **Tailwind CSS** (Paleta Sky + suporte nativo a Tema Claro e Tema Escuro)
- **TanStack Query (React Query)** + **Axios**

## Como executar localmente

```bash
npm install
npm run dev
```

Acesse em `http://localhost:5173`.
